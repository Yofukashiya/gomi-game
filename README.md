# GAME DEV QUEST — プレイアブル発表資料

テックチーム研修（30〜40分）用のスライド。**資料そのものがゲームアプリ**になっていて、
聞き手の前で触りながら「ゲーム制作の全体像」と「AIの使いどころ」を話す構成。

▶ **[ここで開く](https://yofukashiya.github.io/gomi-game/)**

## 操作

| キー | 動作 |
|---|---|
| `→` / `←` | 次 / 前のステージ |
| `Enter` | タイトルから開始 |
| `N` | 発表メモ（各ステージの話す内容）を開閉 |
| `G` | ステージ一覧（好きな場所へジャンプ） |
| `F` | 全画面 |
| 🖥 ボタン | **発表者ビュー**を別ウィンドウで開く（メモ・タイマー・次のステージ） |
| `Space` | ジャンプ調整ラボでジャンプ |
| `WASD` / 矢印 + `Shift` | FINAL BOSS の操作 |

`index.html#13` のように URL の末尾に番号を付けると、そのステージから開く。

### 画面共有するとき

HUD の 🖥 で **発表者ビュー**（`presenter.html`）を別ウィンドウに開く。メモ・経過タイマー・次のステージが出て、`←` `→` でスライド側を操作できる（同一ブラウザ内で `BroadcastChannel` 同期・サーバ不要）。

配信では **「画面全体」ではなく「スライドのウィンドウ」を共有**すること。全体を共有するとメモも映る。

## 構成

```
index.html          全ステージのマークアップと発表メモ（data-note）
css/deck.css        デザイン
js/deck.js          ステージ送り・HUD・メモ・EXP
js/labs.js          各ステージのインタラクション（ジャンプ物理・診断・3Dモデル…）
js/collide.js       当たり判定ラボ（3D・すり抜け実演）
js/world3d.js       全ステージ共通の3D背景（WORLDごとに色とカメラが変わる）
presenter.html      発表者ビュー（別ウィンドウ・共有しない側）
js/boss.js          FINAL BOSS（Three.js・音なし）
vendor/three.min.js Three.js を同梱（CDN依存なし＝会場のネットが死んでも動く）
assets/             各エンジンのエディタ実画面
tools/gen_assets.py 画像生成スクリプト（任意・APIキー必要）
```

- 外部リクエストは0。オフラインで動く。
- 音は出ない（研修会場向け）。
- 3Dモデル・テクスチャはすべてコード生成。モデルファイル0個。

## 更新したら（重要）

GitHub Pages はアセットに `max-age=600` を付ける。CSS/JSを直したら `index.html` の
`?v=1` を全部インクリメント（`?v=2` …）してから push すること。
これを忘れると、事前にページを開いた人は最大10分間ふるいコードで遊ぶことになる。

```bash
sed -i '' 's/?v=2"/?v=3"/g' index.html    # 数字は毎回上げる
```
