# GAME DEV QUEST — プレイアブル発表資料

テックチーム研修（30〜40分）用のスライド。**資料そのものがゲームアプリ**になっていて、
聞き手の前で触りながら「ゲーム制作の全体像」と「AIの使いどころ」を話す構成。

▶ **[ここで開く](https://yofukashiya.github.io/gomi-game/)**

## 操作

| キー | 動作 |
|---|---|
| `→` / `←` | 次 / 前のステージ |
| `Enter` | タイトルから開始 |
| `N` | 発表メモ（各ステージの話す内容）を開閉 |
| `G` | ステージ一覧（好きな場所へジャンプ） |
| `F` | 全画面 |
| `Space` | ジャンプ調整ラボでジャンプ |
| `WASD` / 矢印 + `Shift` | FINAL BOSS の操作 |

`index.html#12` のように URL の末尾に番号を付けると、そのステージから開く。

## 構成

```
index.html          全ステージのマークアップと発表メモ（data-note）
css/deck.css        デザイン
js/deck.js          ステージ送り・HUD・メモ・EXP
js/labs.js          各ステージのインタラクション（ジャンプ物理・診断・3Dモデル…）
js/boss.js          FINAL BOSS（Three.js・音なし）
vendor/three.min.js Three.js を同梱（CDN依存なし＝会場のネットが死んでも動く）
assets/             各エンジンのエディタ実画面
tools/gen_assets.py 画像生成スクリプト（任意・APIキー必要）
```

- 外部リクエストは0。オフラインで動く。
- 音は出ない（研修会場向け）。
- 3Dモデル・テクスチャはすべてコード生成。モデルファイル0個。

## ローカルで開く

```bash
python3 -m http.server 8765
open http://localhost:8765/
```
